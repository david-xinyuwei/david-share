🔬 Key Findings:
  • 16% inference speedup on Qwen-Image-Edit-2511 (20B MMDiT model) using torch.compile
  • Deep analysis of PyTorch's three-layer optimization framework (TorchDynamo → TorchInductor → CUDA Graphs)
  • Critical bug discovered: dynamic=True causes NaN output due to TorchInductor complex64 bug
  • Production recommendation: dynamic=None + suppress_errors=True for safe partial compilation
🇨🇳 Customer Requirements from China Market:

Our Chinese e-commerce customers (fashion/retail industry) have very strict requirements for virtual try-on quality:

  1. Garment detail preservation – Button count must remain exactly the same (e.g., 8 buttons → 8 buttons, not 6 or 7)
  2. Model pose consistency – The model's posture, head position, and body alignment must stay identical before and after clothing replacement

These requirements pushed us to conduct extensive prompt engineering experiments to maximize detail preservation. The repo documents our findings: explicit English prompts with hardcoded counts ("EXACTLY 8 BUTTONS") work better than generic prompts, revealing a fundamental limitation in current diffusion models' counting ability.

Test Environment: NVIDIA A100-80GB PCIe, PyTorch 2.5.0, diffusers 0.37.0

The README includes detailed technical analysis with Mermaid diagrams, bilingual documentation (EN/CN), and reproducible benchmark scripts.
