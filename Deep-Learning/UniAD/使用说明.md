## 📋 完整部署流程 (从零开始)

### 第1步: 创建基础环境

```bash
# 创建conda环境
conda create -n uniad_fa2 python=3.8 -y
conda activate uniad_fa2

# 安装PyTorch (CUDA 11.8示例)
pip install torch==2.0.1 torchvision==0.15.2 --index-url https://download.pytorch.org/whl/cu118

# 或者CUDA 12.1版本
# pip install torch==2.0.1 torchvision==0.15.2 --index-url https://download.pytorch.org/whl/cu121

# 验证CUDA可用性
python -c "import torch; print(f'CUDA可用: {torch.cuda.is_available()}, 版本: {torch.version.cuda}')"
```

### 第2步: 克隆原始UniAD仓库

```bash
# 克隆官方UniAD仓库
git clone https://github.com/OpenDriveLab/UniAD.git
cd UniAD

# 切换到稳定分支 (推荐v2.0)
git checkout v2.0

# 记录路径供后续使用
export UNIAD_ROOT=$(pwd)
echo "UniAD安装在: $UNIAD_ROOT"
```

### 第3步: 安装UniAD依赖

```bash
cd $UNIAD_ROOT

# 安装MMCV (重要: 匹配你的CUDA版本)
# CUDA 11.8版本
pip install mmcv-full==1.6.0 -f https://download.openmmlab.com/mmcv/dist/cu118/torch2.0/index.html

# CUDA 12.1版本
# pip install mmcv-full==1.6.0 -f https://download.openmmlab.com/mmcv/dist/cu121/torch2.0/index.html

# 安装MMDetection
pip install mmdet==2.28.2

# 安装MMSegmentation
pip install mmsegmentation==0.30.0

# 安装MMDetection3D
git clone https://github.com/open-mmlab/mmdetection3d.git
cd mmdetection3d
git checkout v1.0.0rc6
pip install -e .
cd ..

# 安装其他依赖
pip install yapf==0.40.1 einops lyft_dataset_sdk networkx==2.2 numba==0.53.0 numpy pandas plyfile scikit-image tensorboard trimesh==2.35.39

# 验证安装
python -c "import mmcv; import mmdet; import mmdet3d; print('✓ 所有MM系列包安装成功')"
```

### 第4步: 下载NuScenes数据集 (测试用,可选)

```bash
# 创建数据目录
mkdir -p $UNIAD_ROOT/data/nuscenes

# 从 https://www.nuscenes.org/download 下载
# 需要的文件:
# - 完整数据集 (v1.0) trainval: ~300GB
# 或快速测试用:
# - Mini数据集: ~5GB

# 解压到 data/nuscenes/
# 预期目录结构:
# data/nuscenes/
# ├── maps/
# ├── samples/
# ├── sweeps/
# ├── v1.0-trainval/
# └── v1.0-test/ (可选)

# 准备数据 (从UniAD根目录运行)
cd $UNIAD_ROOT
python tools/create_data.py nuscenes --root-path ./data/nuscenes --out-dir ./data/nuscenes --extra-tag nuscenes
```

### 第5步: 安装FlashAttention-2

```bash
# 安装FlashAttention (FA2配置必需)
pip install flash-attn>=2.4.2 --no-build-isolation

# 这可能需要5-10分钟编译
# 验证安装
python -c "import flash_attn; print(f'FlashAttention版本: {flash_attn.__version__}')"
```

### 第6步: 部署FlashAttention代码到UniAD

## 🐛 常见问题

### Q1: 找不到 flash_attn 模块

**错误**: `ModuleNotFoundError: No module named 'flash_attn'`

**解决**:
```bash
pip install flash-attn>=2.4.2 --no-build-isolation
```

**备选**: 使用 `base_track_map_fp16.py` (不需要FlashAttention)

### Q2: CUDA内存不足

**错误**: `CUDA out of memory`

**解决**:
```python
# 方案1: 启用梯度检查点 (修改配置)
model = dict(
    pts_bbox_head=dict(
        transformer=dict(decoder=dict(with_cp=True))
    )
)

# 方案2: 使用FP16或FA2配置 (内存占用更低)
```

### Q3: 加速不明显

**原因**: 
- 单卡训练,batch size=1 → FA2优势有限 (2.6%提升是正常的)
- 多卡训练 (8-16卡) 可以看到10-15%额外提升

**验证**: 检查GPU利用率应 >90%
```bash
nvidia-smi dmon -s u -d 1
```

### Q4: Loss收敛异常

**症状**: Loss变成NaN或持续上升

**解决**:
```python
# 使用动态loss scaling
fp16 = dict(loss_scale='dynamic')

# 或降低学习率
optimizer = dict(lr=1e-4)  # 默认2e-4
```
