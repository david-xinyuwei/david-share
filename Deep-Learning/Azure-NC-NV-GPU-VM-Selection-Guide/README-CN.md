## 核心概念：GPU 不只是"算力"

### 常见误区

| 误区                  | 真相                                                |
| --------------------- | --------------------------------------------------- |
| "GPU = TFLOPS"        | TFLOPS 只衡量 Tensor/CUDA Core 算力，不代表整体能力 |
| "显存大 = 什么都能跑" | 能加载 ≠ 能跑完全流程（可能缺编码器无法输出）      |
| "数据中心卡 = 万能"   | NC H100 无法做视频转码，NV A10 可以                 |

### 正确的思维模型

**GPU = 多个专用硬件单元的组合**

```
┌─────────────────────────────────────────────────────────────────┐
│                         NVIDIA GPU                               │
├─────────────────┬─────────────────────┬─────────────────────────┤
│   📥 解码       │     🧠 计算引擎      │      📤 编码          │
├─────────────────┼─────────────────────┼─────────────────────────┤
│  NVDEC (视频)   │  CUDA Core (通用)   │   NVENC (视频)          │
│  NVJPG (图像)   │  Tensor Core (AI)   │   NVJPG (图像)          │
│                 │  RT Core (光追)     │                         │
└─────────────────┴─────────────────────┴─────────────────────────┘
```

**关键洞察**: 不同 GPU 的硬件单元组合不同，这决定了它们能做什么、不能做什么。

## 六大硬件单元详解

### 1. NVDEC - 视频解码器

| 属性               | 说明                                      |
| ------------------ | ----------------------------------------- |
| **功能**     | 将压缩视频（H.264/H.265/AV1）解码为原始帧 |
| **类比**     | 类似解压 ZIP 文件                         |
| **应用场景** | 视频播放、视频 AI 分析的预处理            |

### 2. NVENC - 视频编码器

| 属性                | 说明                                     |
| ------------------- | ---------------------------------------- |
| **功能**      | 将原始帧压缩为视频文件（MP4 等）         |
| **类比**      | 类似压缩成 ZIP 文件                      |
| **应用场景**  | 直播推流、视频导出、云游戏               |
| **⚠️ 关键** | **NC H100 / NC A100 没有 NVENC** |

### 3. NVJPG - JPEG 硬件引擎

| 属性               | 说明                                                   |
| ------------------ | ------------------------------------------------------ |
| **功能**     | 硬件加速的 JPEG 编解码                                 |
| **应用场景** | 图像预处理流水线、批量图像处理                         |
| **支持 GPU** | NC H100 (7个), NC A100 (5个), RTX PRO 6000 BSE (Blackwell) |

### 4. Tensor Core - 张量核心

| 属性               | 说明                                                  |
| ------------------ | ----------------------------------------------------- |
| **功能**     | 加速 AI 训练/推理的矩阵乘法                           |
| **应用场景** | LLM、Stable Diffusion、视频生成 AI                    |
| **代际**     | 第3代 (Ampere) → 第4代 (Hopper) → 第5代 (Blackwell) |

### 5. RT Core - 光线追踪核心

| 属性                | 说明                                                                   |
| ------------------- | ---------------------------------------------------------------------- |
| **功能**      | 硬件加速的光线追踪计算                                                 |
| **应用场景**  | 游戏光追、3D 渲染、CAD 实时预览                                        |
| **⚠️ 关键** | **NC H100 / NC A100 没有 RT Core**                             |
| **说明**      | NV A10 有 72 个 RT Core (第2代)，RTX PRO 6000 BSE 有188个第4代 RT Core |

### 6. CUDA Core

| 属性               | 说明                    |
| ------------------ | ----------------------- |
| **功能**     | 通用并行计算            |
| **应用场景** | 所有 GPU 计算任务的基础 |

| 规格                | NC H100 (NCads_H100_v5) | NC A100 (NC_A100_v4) | RTX PRO 6000 BSE (NCv6) | NV A10 (NVadsA10_v5) |

| **架构**      | Hopper                  | Ampere               | Blackwell               | Ampere               |

### 定位总结

| GPU                        | 定位          | 优势                                 | 限制                 |
| -------------------------- | ------------- | ------------------------------------ | -------------------- |
| **NC H100**          | 纯 AI 算力卡  | 最强 Tensor Core，94GB HBM3          | 无 NVENC，无 RT Core |
| **NC A100**          | AI 训练/推理  | 生态成熟，80GB HBM2e                 | 无 NVENC，无 RT Core |
| **RTX PRO 6000 BSE** | 全能专业卡    | 硬件单元齐全，完整流水线，96GB GDDR7 | 无 NVLink            |
| **NV A10**           | 推理/图形/VDI | 有 NVENC + RT Core，支持分片 GPU     | 显存较小 (24GB)      |

## 选型决策树

### 三个关键问题

选择 GPU 前，先回答这三个问题：

| # | 问题                           | 如果是                    |
| - | ------------------------------ | ------------------------- |
| 1 | **需要视频编码输出？**   | → 排除 NC H100 / NC A100 |
| 2 | **需要光线追踪？**       | → 排除 NC H100 / NC A100 |
| 3 | **模型能放进单卡显存？** | 否 → 需要多卡 + NVLink   |

## 实战案例分析

### 案例 1：AI 视频生成服务（CogVideo / Open-Sora 类）

**需求**: 使用 CogVideoX 或 Open-Sora 等开源模型构建文生视频服务，输出 MP4 文件

**流水线分析**:

```
文本输入 → DiT 模型推理 → 帧序列 → MP4 输出
            (Tensor Core)   (显存中)   (NVENC)
```

**硬件需求**:

- Tensor Core: 用于 AI 生成
- 大显存: 视频模型很大（CogVideoX-5B 需要约 40GB）
- NVENC: 用于编码输出

**结论**:

| GPU              | 生成                 | 编码        | 结论                 |
| ---------------- | -------------------- | ----------- | -------------------- |
| NC H100          | ✅ 强                | ❌ 无 NVENC | 能生成，无法直接输出 |
| NC A100          | ✅ 强                | ❌ 无 NVENC | 能生成，无法直接输出 |
| RTX PRO 6000 BSE | ✅ 强                | ✅ 有 NVENC | **端到端方案** |
| NV A10           | ⚠️ 显存受限 (24GB) | ✅ 有 NVENC | 可能放不下大模型     |

### 案例 2：云游戏平台

**需求**: 在云端渲染游戏，串流到用户设备

**流水线分析**:

```
用户输入 → 游戏渲染 → 帧捕获 → 串流
           (RT Core + CUDA) (显存中) (NVENC)
```

**结论**:

| GPU              | 光追          | 编码         | 结论               |
| ---------------- | ------------- | ------------ | ------------------ |
| NC H100          | ❌ 无 RT Core | ❌ 无 NVENC  | **不适用**   |
| NC A100          | ❌ 无 RT Core | ❌ 无 NVENC  | **不适用**   |
| RTX PRO 6000 BSE | ✅ 188个第4代 | ✅ 2个编码器 | **极佳选择** |
| NV A10           | ✅ 72个第2代 | ✅ 1个编码器 | **良好选择** |

### 案例 3：LLM 训练（70B 参数）

**需求**: 微调 Llama 3 70B 模型

**显存需求** (BF16):

- 模型参数: ~140GB
- 优化器状态: ~280GB (Adam)
- 梯度: ~140GB
- 总计: 单卡放不下，需要多卡并行

**结论**:

| GPU              | 显存  | NVLink | 结论               |
| ---------------- | ----- | ------ | ------------------ |
| NC H100 × 2     | 188GB | ✅     | **良好选择** |
| NC A100 × 4     | 320GB | ✅     | **良好选择** |
| RTX PRO 6000 BSE | 96GB  | ❌ 无  | 无法高效做张量并行 |
| NV A10           | 24GB  | ❌ 无  | **不适用**   |

### 案例 4：视频监控 AI 分析

**需求**: 实时分析 100 路摄像头

**流水线分析**:

```
摄像头输入 → 解码 → AI 推理 → 结果 (JSON)
 (H.264/265)  (NVDEC) (Tensor Core)
```

**注意**: 不需要 NVENC（输出是 JSON，不是视频）

**结论**:

| GPU              | NVDEC 数量 | 推理         | 结论                   |
| ---------------- | ---------- | ------------ | ---------------------- |
| NC H100          | 7个        | 非常强       | **最适合高并发** |
| NC A100          | 5个        | 强           | **良好平衡**     |
| RTX PRO 6000 BSE | 4个        | 非常强 (5代) | **良好选择**     |
| NV A10           | 2个        | 中等         | 并发较低               |

### 案例 5：AI 训练数据预处理（批量 JPEG 解码）

**需求**: 解码数百万张 JPEG 图片用于深度学习训练数据集

**流水线分析**:

```
JPEG 图片 → 硬件解码 → 原始像素 → 数据增强 → 训练
 (存储)      (NVJPG)   (显存中)    (CUDA 核)   (Tensor Core)
```

**硬件需求**:

- NVJPG: 硬件加速 JPEG 解码，实现高吞吐量
- 大显存: 批量处理需要缓冲空间
- 高带宽: 数据供给速度需要跟上 GPU 计算

**为什么 NVJPG 重要**:

| 方法 | 吞吐量 | CPU 占用 | 适用场景 |
|------|--------|---------|----------|
| CPU 解码 (libjpeg) | ~500 张/秒 | 高 | 遗留系统 |
| GPU 软件解码 | ~2,000 张/秒 | 低 | 通用场景 |
| **NVJPG 硬件加速** | ~10,000+ 张/秒 | 接近零 | 高吞吐训练 |

**结论**:

| GPU              | NVJPG 支持 | 单元数 | 结论                       |
| ---------------- | ---------- | ------ | -------------------------- |
| NC H100          | ✅         | 7个    | **最适合海量数据集** |
| NC A100          | ✅         | 5个    | **极佳选择**         |
| RTX PRO 6000 BSE | ✅         | 支持   | **良好选择**         |
| NV A10           | ❌         | 无     | 回退到 GPU 软件解码        |

> ⚠️ **重要提示**: A10 尽管是 Ampere 架构，但**没有 NVJPG 硬件**。JPEG 解码会使用 GPU 软件路径 (nvJPEG HYBRID 后端)，速度较慢但功能正常。nvJPEG 硬件加速仅支持：**Ampere (A100, A30)、Hopper、Ada、Blackwell**。

**nvJPEG 后端模式**:

| 后端 (Backend) | 说明 | 使用硬件 |
|---------------|------|----------|
| `NVJPEG_BACKEND_HARDWARE` | 纯硬件解码 | NVJPG 专用单元 |
| `NVJPEG_BACKEND_GPU_HYBRID` | GPU 辅助解码 | CUDA Cores (软件实现) |
| `NVJPEG_BACKEND_HYBRID` | CPU+GPU 混合 | CPU 做 Huffman，GPU 做其他 |
| `NVJPEG_BACKEND_DEFAULT` | 自动选择 | 库自动判断 |

**A10 的 Fallback 行为**:
```
A10 调用 nvjpegDecode()：
    → 检测 NVJPEG_BACKEND_HARDWARE 是否可用？
    → A10: ❌ 无 NVJPG 硬件单元
    → 自动 fallback 到 NVJPEG_BACKEND_GPU_HYBRID
    → (使用 CUDA Cores 软件实现 JPEG 解码)
```

**性能影响**:

| GPU | NVJPG 硬件 | 解码路径 | 相对性能 |
|-----|-----------|---------|----------|
| H100/A100/RTX PRO 6000 BSE | ✅ 有 | 硬件加速 | **100%** |
| A10 | ❌ 无 | GPU 软件 (HYBRID) | ~20-30% |
| 纯 CPU | - | libjpeg | ~5% |

> 对于不需要超高吞吐量的场景（比如推理前加载单张图片），A10 完全够用。

> 💡 **注意**: NVJPG 用于**数据预处理**，不是用于 **AI 图像生成**。Stable Diffusion / FLUX 使用标准库输出 PNG/JPEG，不需要 NVJPG 硬件。

| 大显存 (>48GB)  | ✅ 94GB | ✅ 80GB | ✅ 96GB          | ❌ 24GB |
| NVLink 多卡     | ✅      | ✅      | ❌               | ❌      |
| 分片 GPU        | ❌      | ❌      | ❌               | ✅      |

---

## 总结：三大原则

1. **需要视频编码输出？** → 必须有 NVENC → **排除 NC H100 / NC A100**
2. **需要光线追踪？** → 必须有 RT Core → **排除 NC H100 / NC A100**（RTX PRO 6000 BSE和NV A10 有 RT Core）
3. **纯 AI 计算？** → 看 Tensor Core + 显存
