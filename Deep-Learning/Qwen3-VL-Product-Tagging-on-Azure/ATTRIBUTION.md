The public sample images in `data/sample_images/` include:

- `synthetic_jacket.png`: a synthetic schema smoke-test image generated by this repo.
- `fashionpedia_val_00000.jpg` and `fashionpedia_val_00001.jpg`: public Fashionpedia reference-dataset validation samples used to show real input-image analysis examples.

The same two Fashionpedia sample images are also copied under `images/` so README previews and delivery checks can render them directly.
