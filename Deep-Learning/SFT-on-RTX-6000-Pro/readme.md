# SFT on RTX 6000 Pro

> **Author**: Xinyu Wei (魏新宇) — Microsoft AI GBB Senior System Engineer

## Overview

Supervised Fine-Tuning (SFT) experiments and benchmarks on NVIDIA RTX 6000 Pro Ada Generation GPUs on Azure NC v6 series VMs.

## Key Topics

- Fine-tuning LLMs on professional GPUs
- Azure NC v6 VM configuration
- Training performance metrics
- LoRA and full fine-tuning comparison

## Getting Started

### Prerequisites

- Python 3.10+
- Azure subscription (for cloud resources)
- CUDA-compatible GPU (recommended)

### Setup

```bash
git clone <this-repo-url>
cd SFT-on-RTX-6000-Pro
```

## Running on Azure

This project is designed to run on Azure GPU VMs. Refer to the scripts and notebooks for specific configuration details.
