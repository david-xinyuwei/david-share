Welcome to the Azure Agent Skills In Action briefing. Microsoft published two skills repositories: azure-skills with 26 top-level skills covering Azure resource management, and microsoft/skills with 174 skills across Python, .NET, TypeScript, Java, and Rust. To verify these skills actually work, we ran every callable Azure MCP tool against a real subscription with Owner permission. 45 out of 63 tools executed successfully and returned live Azure data. 9 had valid schemas but needed specific resources we didn't have provisioned. Then we used 12 individual skills to produce real deliverables: a production architecture document following the 7-step WAF review, structured GitHub issues from raw error logs, a working MCP server, a UI design review scoring 5.7 out of 10, KQL monitoring queries, and a 14-slide presentation where every fact was sourced from learn.microsoft.com. The verdict: these skills are not promotional documentation. They produce real engineering artifacts when loaded into a coding agent and given a concrete task. Any customer can audit every claim by running the same harness against their own Azure subscription. This podcast itself was generated using the podcast-generation skill from microsoft/skills, demonstrating that skills can produce audio output, not just text and code.
