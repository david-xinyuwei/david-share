Sharing a practical evaluation I did with a GCR PC OEM (Lenovo Qira team) on how to run agent-generated code safely on Windows AIPC devices. The key question: if an on-device AI assistant needs to execute local actions, what's the architecture?

Two implementation paths (from Build 2026 BRK262 / KEY01):

Path A: MAF-basedPath B: MXC + ProcessContainer
Use whenFull agent workflow: plan, tools, HITL, CodeAct, recoveryJust need controlled local execution, no agent loop
ExecutionMAF carries the reasoning loop; Hyperlight sandbox for generated codeMXC policy selects ProcessContainer (default) or Hyperlight
ProvenMAF + Hyperlight CodeAct + 4 host tools live on Windows VMMXC 0.7 network/filesystem/UI policy + task-scoped capability catalog

Running on Azure: The evaluation used Azure OpenAI (gpt-5.4 via APIM) for cloud reasoning + a Standard Windows VM (simulating the customer AIPC) for local execution. In production, the AIPC is the customer's device — Azure consumption is mainly AOAI token usage (cloud model calls) + APIM gateway. For customers deploying Hyperlight/CodeAct at scale, there's also potential for Foundry Hosted Agent consumption on the cloud side.

Key results:

CapabilityPath A (MAF)Path B (MXC)
Network block/allowN/A (framework level)✅ Proven: curl exit=6 blocked, exit=0 allowed
Filesystem scopingN/A✅ readwritePaths works on stock Win11
Task-scoped UI policyN/A✅ text=blocked, drawing=allowed (same executable)
Sandbox code execution✅ Hyperlight micro-VM, 36ms first turnProcessContainer for lighter tasks
Cross-turn state✅ 4 turns, variables persistProto branch (not mainline yet)
Host tool callbacks✅ read_csv, screenshot, system_info, list_filesN/A (MXC doesn't own tool callbacks)

Why this matters for Azure business: Lenovo is evaluating Windows agent execution for Qira (their AIPC OS agent). If they adopt MAF + Hyperlight, that's AOAI consumption + Foundry hosting. If they adopt MXC for local policy governance, that's a Windows platform play that still requires AOAI for the reasoning layer. Either path = Azure AI token consumption as the cloud backbone.
