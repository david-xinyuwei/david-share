# Best Practices for MaaS and SLM

> **Author**: Xinyu Wei (魏新宇) — Microsoft AI GBB Senior System Engineer

## Overview

Best practices and guidelines for deploying Models-as-a-Service (MaaS) and Small Language Models (SLM) on Azure AI.

## Key Topics

- MaaS deployment patterns
- SLM selection and optimization
- Cost-performance trade-offs
- Azure AI model catalog usage

## Getting Started

### Prerequisites

- Python 3.10+
- Azure subscription (for cloud resources)
- CUDA-compatible GPU (recommended)

### Setup

```bash
git clone <this-repo-url>
cd Best-practices-for-MaaS-and-SLM
```

## Running on Azure

This project is designed to run on Azure GPU VMs. Refer to the scripts and notebooks for specific configuration details.
