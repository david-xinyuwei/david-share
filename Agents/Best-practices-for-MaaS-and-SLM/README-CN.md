# Best Practices for MaaS and SLM

> **作者**: 魏新宇 (Xinyu Wei) — 微软 AI GBB 高级系统工程师

## 概述

Best practices and guidelines for deploying Models-as-a-Service (MaaS) and Small Language Models (SLM) on Azure AI.

## 核心主题

- MaaS deployment patterns
- SLM selection and optimization
- Cost-performance trade-offs
- Azure AI model catalog usage

## 快速开始

### 前提条件

- Python 3.10+
- Azure 订阅（用于云资源）
- CUDA 兼容 GPU（推荐）

### 环境搭建

```bash
git clone <this-repo-url>
cd Best-practices-for-MaaS-and-SLM
```

## 在 Azure 上运行

本项目设计在 Azure GPU VM 上运行。详细配置请参考脚本和 Notebook。
