# Evidence index

This directory contains public-safe, machine-readable evidence. It does not
contain service endpoints, credentials, private work identifiers, or raw live
telemetry.

| Evidence | Classification | Generated by / source | What it supports | Boundary |
|---|---|---|---|---|
| [`public-sdk-contract.json`](public-sdk-contract.json) | dynamic-runtime | `python scripts/verify_public_resilience_api.py --format json --output evidence/public-sdk-contract.json` | The 18 public SDK surface checks on the pinned packages | Offline package probe; not live Hosted Agent recovery |
| [`resilience-sdk-usage.json`](resilience-sdk-usage.json) | dynamic-runtime | `python examples/resilience_sdk_usage.py --check --format json --output evidence/resilience-sdk-usage.json` | Real package import and `@task` decorator registration for the visible SDK-usage example | Does not execute the handler body and is not live Hosted Agent recovery |

| [`recovery-contract-events.jsonl`](recovery-contract-events.jsonl) | structured runtime log | Same command as above | Ordered state transitions, worker/process identity, generation, entry mode, checkpoint, phase, hashes | Synthetic public-safe workload |

## Reproduce the public-safe evidence

From this directory's parent:

On Windows without long-path support, run these commands from a short clone path.

```powershell
New-Item -ItemType Directory -Force .demo-state | Out-Null

python scripts\recovery_contract_demo.py demo `
  --work-id public-reference-001 `
  --payload "public-safe resilience contract payload" `
  --phases 5 --crash-after 1 --lease-seconds 0.5 `
  --summary-file .demo-state\recovery-contract-demo.json `
  --events-file .demo-state\recovery-contract-events.jsonl

python scripts\validate_observations.py self-test `
  --output .demo-state\observation-validation.json

python scripts\verify_public_resilience_api.py --format json `
  --output .demo-state\public-sdk-contract.json

python hosted-agent\run_local_recovery.py `
  --python <path-to-python-with-agentserver-2.1.0b2> `
  --report .demo-state\owned-hosted-agent-local.json
```

Timestamps and local process IDs in JSONL are expected to change on a new run.
The semantic checks, event order, generations, phases, and exit codes must still
pass. These commands intentionally do not overwrite committed evidence. A
maintainer who refreshes committed evidence must review the diff, regenerate
`manifest.json`, and rerun `scripts/validate_repo.py`.
