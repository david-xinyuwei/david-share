# Notice

- **The measured data** under `results/` comes from one run by the author on 27 November 2026, in one Microsoft 365 tenant, as one signed-in user who read his own data. It holds counts, sizes, times, field names and error texts. It holds no mail, chat, file or meeting content, no item ID, no address and no request ID of the service. The complete answers were kept in a private folder and are not part of this repository.
- **The tool list** (`results/tools_list.json`) is the list of tools, with descriptions and parameters, that the Work IQ MCP endpoint returned to the Interactive Demo page on the test day. It is Microsoft's text, reproduced unchanged as the record of what was tested, and it can differ in another tenant or on another day.
- **The screenshots** (`images/ui_*.png`) are real pictures of Microsoft's [Interactive Demo page for Work IQ MCP](https://interactivedemo.microsoft.com/work-iq/mcp?server=workiq-remote), taken by the author in Live mode during the calls they show. Each was cut below the answer, and grey boxes cover item IDs, ETags, the user's object ID and the request IDs of the service; nothing else was changed. The name at the top right is the author's own account. `images/SOURCES.json` lists each picture with the SHA-256 of its original, the number of boxes and what they cover.
- **Two pictures are Microsoft's slides** (`images/official_BRK302_slide13.png`, `images/official_BRK302_slide14.png`): slides 13 and 14 of the Ignite 2026 session BRK302, "Build personalized AI experiences with Work IQ", each exported whole and unchanged from the deck that the [session page](https://ignite.microsoft.com/en-US/sessions/BRK302) offers for download without sign-in. They are Microsoft's work, shown as the vendor's own description of the tools that this test measured. `images/SOURCES.json` lists the address and the SHA-256 of the deck.
- **The overview figure, the test-setup figure and the chart** (`images/limits-overview-*.png`, `images/test-topology-*.png`, `images/retrieve-snippets-*.png`) are original explanatory diagrams by the author. They are not official Microsoft diagrams. Their numbers are read from `results/limits.json` and `results/summary/retrieve.json`.
- **Microsoft 365 architecture icons** are used unmodified in the two diagrams, under the terms on Microsoft's [icon page](https://learn.microsoft.com/en-us/previous-versions/microsoft-365/solutions/architecture-icons-templates): "Microsoft permits the use of these icons in architectural diagrams, training materials, or documentation." `images/SOURCES.json` lists the package and the SHA-256 of each icon.
- **Quotations from Microsoft Learn** in the README and under `docs/` are short passages of the pages they link to, as those pages read on 27 November 2026; the tool reference showed 20 November 2026 as its date of last update.
- **No third-party code** is included. The scripts need Python, Microsoft Edge and the package [`websocket-client`](https://pypi.org/project/websocket-client/); `scripts/redact_shot.py` also needs [`pillow`](https://pypi.org/project/pillow/). Neither package is redistributed.
- **Work IQ, Microsoft 365, Microsoft Graph and Microsoft Edge** are products of Microsoft. This repository is the author's own test and is not a statement by Microsoft about those products.
