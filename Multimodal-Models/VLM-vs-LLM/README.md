# VLM vs LLM: Vision-Language Model Comparison

> **Author**: Xinyu Wei (魏新宇) — Microsoft AI GBB Senior System Engineer

## Overview

Comparison and benchmarks between Vision-Language Models (VLMs) and Large Language Models (LLMs) for multimodal tasks on Azure.

## Key Topics

- VLM vs LLM architecture differences
- Multimodal task benchmarks
- Use case selection guide

## Getting Started

### Prerequisites

- Python 3.10+
- Azure subscription (for cloud resources)
- CUDA-compatible GPU (recommended)

### Setup

```bash
git clone <this-repo-url>
cd VLM-vs-LLM
```

## Running on Azure

This project is designed to run on Azure GPU VMs. Refer to the scripts and notebooks for specific configuration details.
