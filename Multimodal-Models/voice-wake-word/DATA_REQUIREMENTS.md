# Data Requirements

This project requires the following data files to run the notebook. Due to their large size, they are **not included in this repository** and must be obtained separately.

## Required Files

### 1. Positive Training Samples
- **Filename**: `turn_on_the_office_lights_features_2.npy`
- **Size**: ~33 MB
- **Content**: 3,203 feature vectors extracted from positive wake word audio samples
- **Format**: NumPy array of shape (3203, 2688)
- **Description**: Mel-frequency spectral features from wake word "turn on the office lights"

### 2. Negative Training Samples
- **Filename**: `negative_features_2.npy`
- **Size**: ~50 MB
- **Content**: 4,821 feature vectors extracted from negative (non-wake-word) audio samples
- **Format**: NumPy array of shape (4821, 2688)
- **Description**: Background noise and speech without the target wake word

### 3. Test Audio
- **Filename**: `santa_barbara_corpus_test_clip.wav`
- **Size**: ~91 MB
- **Duration**: 49.2 minutes (2,952 seconds)
- **Format**: WAV audio file (16 kHz mono recommended)
- **Description**: Long-form audio for evaluating false positive rates

### 4. Hard Negatives (Generated)
- **Filename**: `hard_negative_features_correct.npy`
- **Size**: ~3.6 MB
- **Content**: 348 hard negative samples
- **Format**: NumPy array of shape (348, 2688)
- **Note**: This file is **generated automatically** by the notebook (Cell 28) during the hard negative mining process. You don't need to provide it initially.

## Obtaining the Data

### Option 1: Generate Your Own Features

You can generate compatible feature files using the following code:

```python
import librosa
import numpy as np

def extract_features(audio_path, sr=16000, n_mels=40, n_fft=512, hop_length=320):
    """Extract mel-frequency features from audio file"""
    audio, _ = librosa.load(audio_path, sr=sr)
    
    # Compute mel spectrogram
    mel_spec = librosa.feature.melspectrogram(
        y=audio, sr=sr, n_mels=n_mels, 
        n_fft=n_fft, hop_length=hop_length
    )
    
    # Convert to log scale
    log_mel = librosa.power_to_db(mel_spec)
    
    # Split into 1.5-second windows with 0.25-second hop
    window_samples = int(1.5 * sr)
    hop_samples = int(0.25 * sr)
    
    features = []
    for i in range(0, len(audio) - window_samples, hop_samples):
        window = audio[i:i + window_samples]
        mel = librosa.feature.melspectrogram(
            y=window, sr=sr, n_mels=n_mels,
            n_fft=n_fft, hop_length=hop_length
        )
        log_mel = librosa.power_to_db(mel).flatten()
        if len(log_mel) == 2688:  # Expected feature dimension
            features.append(log_mel)
    
    return np.array(features)

# Example usage
positive_features = extract_features('your_positive_samples.wav')
np.save('turn_on_the_office_lights_features_2.npy', positive_features)

negative_features = extract_features('your_negative_samples.wav')
np.save('negative_features_2.npy', negative_features)

# For test audio, just save the audio file directly
# No feature extraction needed - the notebook does this in Cell 16
```

### Option 2: Use Pre-existing Datasets

If you have access to wake word datasets (e.g., from previous projects or research), ensure they match these specifications:
- **Sample rate**: 16 kHz
- **Feature dimension**: 2,688 (40 mel bands × 67 time frames)
- **Window size**: 1.5 seconds
- **Hop size**: 0.25 seconds
- **Feature type**: Log-mel spectrogram
