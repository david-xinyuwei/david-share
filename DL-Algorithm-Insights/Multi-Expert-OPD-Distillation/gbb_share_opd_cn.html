分享一下 DeepSeek-V4 的 post-training 架构研究——V4 用 On-Policy Distillation (OPD) 完全替代了 Mixed RL，把 10+ 个领域专家模型融合成一个生产模型。我在 Azure H100 上做了端到端验证。

背景：企业客户有多个 fine-tuned 模型（数学、代码、写作、Agent 等）时，部署 N 个模型 = N 倍推理成本。DeepSeek-V4 用 OPD 解决：在 student 自己的 trajectory 上做 logit 层对齐，把所有专家蒸馏到一个模型。

跑在 Azure 上：全部 11 轮训练和评测都在 Standard_NC80adis_H100_v5（2× H100 NVL，每张 94 GB）上完成。单台 VM 即可跑完全流程，不需要集群。

结果（Run 11，HumanEval 164 题）：

指标基线OPD提升
Greedy pass@122.56%26.22%+3.66 pp
Sampling pass@1（10 次均值）18.72%23.48%+4.76 pp
pass@10（生产指标）49.39%55.49%+6.10 pp

SFT 对照实验证实：跨领域 SFT 导致灾难性遗忘（greedy -5.49 pp），OPD 两个指标都提升。Repo 包含 1900+ 行理论分析、11 轮实验工程记录、完整脚本和成本明细。
